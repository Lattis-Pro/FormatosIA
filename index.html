CASO 1: MORE NOLE, VIOLETA FABIOLA RECHAZO IA
Errores cometidos en el correo:
  • TIPO DE CRÉDITO: Declararon SUBROGADO (No existe en el catálogo IA).

Corrección Reglamentaria:

TIPO DE CRÉDITO debe ser COMPRA DE DEUDA.

COMENTARIOS debe redactarse: 00444 - Scotiabank.

Asunto correcto: Remesa – Provincia – PNP – MORE NOLE, VIOLETA FABIOLA – 70140510

  • COMENTARIOS: Repitieron PRÉSTAMO NUEVO.
Corrección Reglamentaria:

TIPO DE CRÉDITO debe ser LIBRE DISPONIBILIDAD.

COMENTARIOS para operaciones nuevas debe ser obligatoriamente: 0 - Nuevo.

DNI cliente: 71864212 | Monto: S/ 65,000.00 | Cuota: S/ 1280.28
CASO 3: RUIZ SILVA LEYDI YURITZA ERROR COMENTARIOS "0"
Errores cometidos en el correo:
  • COMENTARIOS: Escribieron solo 0 sin la etiqueta complementaria.
  • Convenio: DIRIS LC (Correcto). Tipo: LIBRE DISPONIBILIDAD (Correcto).

El algoritmo de IA requiere la cadena completa exacta: 0 - Nuevo.

Asunto: REMESA DIRIS LC - RUIZ SILVA LEYDI YURITZA - DNI 47223407 (Debe cambiarse a guión largo con espacios).
CASO 4: SANCHEZ AREVALO GENI JHOEL SLASHES // PROHIBIDOS
Errores cometidos en el correo:
  • ASUNTO: FILE DESEMBOLSO // PROVINCIA // PNP // SANCHEZ... // DNI: 70901798
  • El uso del token // o la palabra DNI: bloquea la extracción automática de variables.
Corrección Reglamentaria:

Cambiar absolutamente todos los separadores a guión:

File Desembolso – Provincia – PNP – SANCHEZ AREVALO GENI JHOEL – 70901798
